КАК ВКЛЮЧИТЬ ЛИЧНУЮ АДМИН-ПАНЕЛЬ
===================================

На публичном сайте НЕТ кнопки админки.
Ваш закрытый адрес после публикации:
https://ВАШ-САЙТ.netlify.app/owner-panel-manas/

Сам скрытый адрес не является защитой. Настоящая защита сделана через Supabase Auth и RLS:
даже если кто-то узнает адрес, без вашей учётной записи он не сможет добавить, изменить или удалить новости.

1. СОЗДАЙТЕ SUPABASE
--------------------
1) Откройте supabase.com и создайте бесплатный проект.
2) Откройте Project Settings -> API.
3) Скопируйте:
   - Project URL
   - Publishable key (или старый anon public key)
4) Откройте файл supabase-config.js и вставьте эти два значения.

ВАЖНО: никогда не вставляйте Secret key / service_role key в сайт.

2. СОЗДАЙТЕ БАЗУ
----------------
1) В Supabase откройте SQL Editor.
2) Скопируйте туда весь файл supabase-setup.sql.
3) Нажмите Run.

3. СОЗДАЙТЕ ТОЛЬКО СВОЙ АККАУНТ
-------------------------------
1) Откройте Authentication -> Users.
2) Нажмите Add user / Create new user.
3) Укажите свою почту и сильный пароль.
4) Скопируйте UUID созданного пользователя.
5) В самом низу supabase-setup.sql есть строка:

insert into public.admin_users (user_id) values ('ВАШ-UUID-СЮДА') on conflict do nothing;

6) Замените ВАШ-UUID-СЮДА и выполните эту строку в SQL Editor.

4. ЗАПРЕТИТЕ РЕГИСТРАЦИЮ ДРУГИХ
-------------------------------
Authentication -> Sign In / Providers -> Email:
отключите Allow new users to sign up / Enable sign ups.
В админке сайта кнопки регистрации всё равно нет.

5. ЗАГРУЗИТЕ САЙТ НА NETLIFY
---------------------------
Загрузите весь архив сайта. После публикации откройте:
https://ВАШ-САЙТ.netlify.app/owner-panel-manas/

Введите свою почту и пароль.

6. КАК ПУБЛИКОВАТЬ НОВОСТЬ
--------------------------
- Заполните заголовок и текст на KG и RU.
- Выберите обложку. Перед загрузкой сайт сам сожмёт её в WebP.
- Отметьте «Опубликовать сейчас».
- Нажмите «Сохранить новость».

Новость появится:
- на главной странице;
- в разделе «Новости»;
- на отдельной странице статьи.

7. БЕЗОПАСНОСТЬ
---------------
- Не отправляйте никому пароль.
- Не вставляйте Secret key / service_role key в файлы сайта.
- Publishable key не является секретом; права ограничены политиками RLS.
- Для смены пароля используйте Supabase Authentication -> Users.
- Для второго администратора создайте второго пользователя и добавьте его UUID в admin_users.
